NepTLS · v0.4.1

See what happened on the wire.

A clear, dependency-light HTTP client and TLS research toolkit for Python. Explicit transports, useful diagnostics, and an auditable core for authorized testing.

Install from PyPIView source on GitHub

Install in seconds

python -m pip install --upgrade neptls

Release highlights

Zero-dependency corePortable, inspectable Python networking by default.
HTTP/2 + HTTP/3Optional native transports with explicit capability checks.
TLS visibilityConfiguration, fingerprints, ALPN, certificates, timing, and probes.
Safe boundaryBuilt for owned systems and authorized research—not bypasses.

Try it

import neptls

response = neptls.get("https://example.com", impersonate="chrome", timeout=10)
response.raise_for_status()
print(response.status_code, response.http_version)
