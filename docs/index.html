A high-performance, inspectable HTTP client and TLS research engine for Python. Built with standard-library defaults, native HTTP/2, HTTP/3 QUIC, and real browser ClientHello impersonation.

pip install neptls View Documentation
quickstart.py
import neptls # Native HTTP request with browser impersonation & HTTP/2 or HTTP/3 transport response = neptls.get( "https://httpbin.org/headers", impersonate="chrome131", transport="http2", timeout=10, ) response.raise_for_status() print(f"Status: {response.status_code} | Protocol: {response.http_version}")

Engineered for Performance & Visibility

Everything you need for security research, API integration, and networking diagnostics.

⚡

HTTP/2 & HTTP/3 QUIC

Native HTTP/2 via `httpx` and HTTP/3 QUIC via `curl-cffi` with explicit capability checks and non-silent fallback control.

🎭

Browser Impersonation

Versioned TLS ClientHello fingerprinting and header hints matching Chrome 131/133, Firefox 133, Edge 131, and Safari 18.

🔍

TLS Diagnostics

Inspect local TLS configurations, calculate JA3-compatible hashes, probe remote host handshakes, and verify ALPN parameters.

🔄

Async Native

`AsyncClient` built with full feature parity, persistent cookie jar state, connection retries, and non-blocking IO.
