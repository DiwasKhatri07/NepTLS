## Technology credits

NepTLS is built on Python's standard library by default, with optional `httpx` and `curl-cffi` integrations for native HTTP/2 and HTTP/3 transports. PyPI distributes the `neptls` package, and GitHub Actions provides CI and daily repository maintenance.
